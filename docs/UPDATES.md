# Обновления лаунчера

## Как это выглядит

Через пару секунд после запуска лаунчер тихо спрашивает GitHub о последнем релизе
этого репозитория. Если версия новее, появляется окно «Вышла версия X» с описанием
изменений и кнопками «Позже» / «Обновить». В «Настройках» есть кнопка
«Проверить обновления».

По «Обновить» лаунчер:

1. скачивает `update.json` и проверяет его подпись;
2. скачивает установщик в `Data\Updates\` и сверяет размер и SHA-256 с подписанными;
3. запускает установщик в режиме обновления и закрывается;
4. установщик ждёт закрытия лаунчера, ставит новую версию поверх старой
   и снова открывает лаунчер.

Перевод, ручные правки, настройки и резервные копии (`Data`, `Backups`, `Exports`, …)
не трогаются: установщик заменяет только файлы программы из своего манифеста, а файлы
готового перевода копирует, лишь если их ещё нет. Без сети или при любой ошибке
проверки ничего не ставится.

Сам обновляется только **установленный** лаунчер (есть `.install-manifest.json`).
Запуск из исходников или portable-папки проверяет версию, но ставить ничего не будет.

## Почему этому можно доверять

- Запросы идут только по HTTPS на `api.github.com`, `github.com` и хранилище файлов
  GitHub; ссылки должны вести на релизы именно этого репозитория.
- `update.json` подписан **Ed25519**. Публичный ключ зашит в `wuwaru/updater.py`
  (`PUBLIC_KEY`), закрытый хранится только у автора на машине сборки, не в репозитории.
  Подпись покрывает версию, имя файла, размер и SHA-256 установщика, поэтому подменить
  файл в релизе или выдать старый подписанный установщик за новую версию не выйдет.
- Файл `.sha256` рядом с установщиком — для людей; лаунчер верит только подписи.
- Размеры ответов ограничены, недокачанный или несовпавший файл удаляется.

## Как выпустить версию

```powershell
# 1. поднять версию в wuwaru/__init__.py и pyproject.toml
# 2. собрать установщик
.venv\Scripts\python.exe tools\build_installer.py
# 3. подписать и выложить релиз (токен берётся из Git Credential Manager)
.venv\Scripts\python.exe -m tools.release sign
.venv\Scripts\python.exe -m tools.release publish --notes notes.md
```

Ключ подписи создаётся один раз: `python -m tools.release init-key` (кладёт его в
`%USERPROFILE%\.wuwaru-release\` и печатает публичную часть для `PUBLIC_KEY`).
Потерянный ключ заменить можно только новой версией лаунчера с новым `PUBLIC_KEY`,
поставленной вручную.
