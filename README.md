## Что это

Wuthering Waves не поддерживает русский язык. WuWa Russian подключает русский текст
к английской версии игры, **не изменяя ни одного официального файла**: игра сама
загружает наш архив поверх английских текстов через свой штатный механизм
«горячих обновлений».

- **Лаунчер.** Одна кнопка «Играть»: проверяет игру, при необходимости собирает пакет
  перевода, подключает его (один запрос UAC) и запускает игру через Steam.
- **Готовый перевод внутри установщика.** Имена и интерфейс проверены в игре;
  остальные разделы (бой, предметы, задания, диалоги, лор) включаются в настройках.
- **Удаление в один клик.** «Убрать перевод из игры» возвращает её в исходное состояние.
- **Обновляется сам.** Лаунчер проверяет новые версии здесь, в Releases, и ставит их
  поверх с проверкой подписи ([подробнее](docs/UPDATES.md)).
- **Инструменты переводчика** (`WuWaRussian.exe --editor`): база перевода с историей
  правок, глоссарий, проверка качества, машинный перевод с контекстом сцен, экспорт.

## Установка

1. Скачай `WuWaRussian-Setup-<версия>.exe` из [последнего релиза](https://github.com/mitamerlane/wuwa-ru/releases/latest).
2. Запусти. Права администратора не нужны, папка по умолчанию —
   `%LOCALAPPDATA%\Programs\WuWaRussian`.
3. Открой лаунчер → **«Играть»**.

Установщик не подписан сертификатом, поэтому SmartScreen может спросить
«Выполнить в любом случае». Контрольная сумма лежит рядом с файлом (`.sha256`).
Новые версии лаунчер предложит поставить сам; переводы, правки и настройки при
обновлении сохраняются.

## Как это работает

Игра подключает архивы по списку `MountLang_en.txt`. Лаунчер кладёт рядом свой архив
`pakchunk10-WuWaRussian.pak` (английская таблица текстов с русскими строками и шрифт
с кириллицей) и дописывает в список одну строку с правильным SHA-1 этого архива.
Больше ничего: ни EXE, ни подписи, ни оригинальные PAK, ни озвучка не меняются,
античит и Defender не трогаются. Подробно — в [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md).

## Откуда перевод

Английские строки берутся из публичных выгрузок игровых текстов на GitHub по
закреплённой ревизии и контрольной сумме; перевод сделан языковой моделью с контекстом
сцен, говорящим и глоссарием, затем проверен автоматическим валидатором разметки.
Подробности и ограничения — в [docs/TRANSLATION.md](docs/TRANSLATION.md).

## Структура репозитория

```text
wuwaru/              приложение: лаунчер, редактор, ядро перевода, сборка пакета
├─ launcher.py       окно игрока («Играть», «Настройки»)
├─ play_page.py      страница «Играть» и её состояния
├─ native_launch.py  проверка игры и подключение перевода
├─ native_helper.py  запись двух объектов в папку игры через UAC
├─ native_package.py сборка пакета перевода из базы
├─ pak_reader.py     чтение архивов игры (UE PAK V12)
├─ pak_builder.py    запись архива (GPL, на основе WuWaRu)
├─ translation_db.py база перевода: строки, статусы, история, происхождение
├─ engine.py         машинный перевод пакетами, бюджет, повторы
├─ providers.py      провайдеры перевода (OpenAI-совместимые API)
├─ qa.py, validation.py  проверка разметки, плейсхолдеров и длины
├─ updater.py        проверка и загрузка обновлений лаунчера
└─ gui.py, editor.py инструменты переводчика
installer/           установщик и деинсталлятор (PySide6)
packaging/           PyInstaller spec и исходные SVG иконок
tools/               сборка установщика, пакета перевода, публикация релиза
tests/, gui_tests/   автоматические тесты (синтетические данные, игра не нужна)
research/            закреплённые ревизии и хеши публичных источников текстов
docs/                документация
```

Схема модулей — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Сборка из исходников

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[build]"
.venv\Scripts\python.exe -m wuwaru.gui                     # лаунчер из исходников
.venv\Scripts\python.exe -m unittest discover -s tests     # тесты
.venv\Scripts\python.exe tools\build_installer.py          # установщик в dist\
```

Полный порядок, включая готовый перевод и релиз, — [docs/BUILDING.md](docs/BUILDING.md).
